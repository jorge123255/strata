# Connectors account experience

Strata has a dedicated Connectors destination in the Mac sidebar and an iPhone Connectors tab. It follows BotAI’s account-oriented flow: discover a service, connect an account, then choose its tools and bot or team access. Mac connection and pairing settings remain available from Home and the Connectors toolbar on iPhone.

Discover includes every one of the 391 MCP-bearing service listings returned by the public catalog used by BotAI. Exact endpoint aliases are merged while their source IDs and searchable names remain represented. The catalog is bundled for offline discovery; it does not contact all providers when a screen opens. The 70 remaining listings have no MCP server and belong to skills rather than account connectors.

The merged catalog contains 219 direct/custom entries, 161 setup-required entries, and 11 managed entries. The catalog distinguishes direct connections, setup-required integrations, and managed services. Discovery metadata can establish a compatible sign-in protocol; it does not prove that an account can pass vendor consent or organization policy. Public endpoints are enabled only when compatible OAuth discovery or a single explicit bearer-key configuration was verified. New imported OAuth services initially finish sign-in on Mac. No source commands, configuration values, registered client IDs, secrets or hosted-account credentials are imported.

Discover shows service identities, descriptions and the actual account method. Linear, Notion and Atlassian offer browser sign-in. GitHub and Slack currently use API keys and say so. OAuth presets create from the host’s trusted catalog, retain the returned account ID and open its sign-in flow directly. API-key presets use a short account/key form. Accounts can be named and multiple accounts kept for one service. Custom URLs, local programs, imports and registration settings remain under Advanced.

New accounts start without bot, team or tool grants. Existing access controls, inventory revision checks, instructions, approval modes and immediate revocation remain in force. Adding from a bot or team shortcut does not implicitly share the account. New-account navigation clears that shortcut’s filter so the unassigned account remains visible after reopening; explicit account links remain accessible under an unmatched filter.

Mac browser opening is an exact account action. The host opens only that pending account’s validated authorization URL through a fixed system command and argument list. The client cannot supply a URL or command. A visible sign-in link remains available if the system opener fails. The native shell gains no new blanket capability.

Compatible services can sign in through iPhone’s system authentication browser. The fixed `strata://connector-oauth/callback` returns the result through the paired channel; tokens and PKCE verifiers remain on Mac. Completion is bound to the initiating device, current account setup, exact callback and single state. Cancellation carries the captured state, so a delayed cancellation cannot stop a newer login. Local Mac account management can cancel the exact pending request; another paired phone cannot. Cancelling a pending request does not delete saved tokens. Unsupported services and older hosts retain an explicit Finish sign-in on Mac path.

BotAI’s repository and installed Connect Apps page were inspected read-only. Its gallery, named accounts and per-service controls informed this design. Its hosted account broker, registered provider credentials and account tokens were not copied. Google Workspace and Outlook are not advertised as ready-to-use account integrations: Google’s [Gmail setup](https://developers.google.com/workspace/gmail/api/guides/configure-mcp-server) requires provider project/client registration and preview access, while Microsoft’s [enterprise MCP setup](https://learn.microsoft.com/en-us/graph/mcp-server/get-started) requires tenant provisioning. BotAI’s managed Outlook translator is a separate integration. Those services are present as setup cards. Google supports explicitly entering the owner’s registered client in Mac Advanced setup, with the fixed loopback callback `http://127.0.0.1:47841/callback`; its authorization requests offline access and consent. Managed services need an independent adapter before Strata can connect. Figma is also setup-required because its published server limits which clients may connect.

## Validation and activation

Source validation passed: 51 focused host/catalog/extension checks, 9 paired-bridge checks, and 9 UI helper/workspace checks. Typecheck and the production UI build passed. The final Mac component workflow matches all 444 recorded inputs, uses 144 isolated requests, and passed independent source/request/visual review with zero P1/P2 findings.

Native QA caught and fixed a first-presentation preset-sheet race on iPhone; the selected service and its presentation now travel as one item. It also caught a clipped Advanced menu in a narrow Mac window; that menu now stays within the viewport with a real bounds assertion. Failed attempts remain retained.

Final simulator and installed build receipts are recorded here after activation. Intermediate failed driver attempts remain retained and do not count as accepted workflows. No real account login, owner model prompt or owner connector grant is part of the automated acceptance. System browser account consent remains owner acceptance.
