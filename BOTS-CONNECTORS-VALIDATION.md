# Connectors and Grok models

Strata now exposes Connectors inside Bots on Mac and iPhone. The design follows BotAI’s catalog, named accounts, tool controls and account status, using Strata’s existing private MCP runtime. It does not copy BotAI’s cloud account backend or account credentials.

The catalog includes GitHub, Linear, Linear read-only, Slack, Notion, Atlassian and Custom HTTP. Local program configuration remains available on Mac. HTTP setup and bearer keys can be entered on the paired iPhone; OAuth registration settings and the browser callback run on Mac. The phone can share the sign-in link to the Mac, poll status and submit the exact returned callback. Service accounts still need the owner’s authorization. Adding a connector starts no model work and grants no bots, teams or tools automatically.

Owners select personal bot access, team access, enabled tools and connector instructions. Team access is bound to the current enabled team, current member and active same-team run. It never follows members into unrelated private chats or a completed task’s later continuation. New conversations freeze their reviewed tool inventory and instructions; current access is rechecked before execution. Removing access, disabling a connector or signing out revokes use. Existing conversations do not acquire newly added grants. Existing Ask, Plan and Bypass policies continue to apply; a service’s tool annotations cannot establish read-only authority.

Browser sign-in uses the installed MCP SDK with protected-resource discovery, PKCE, state, issuer and resource binding. Redirects are not followed with credentials. Callback expiry, replay, changed setup, superseded sign-ins and token refresh are covered by disposable local-service checks. Connection credentials stay on the host and are removed from public inventories, tool results, structured results, JSON text, approval labels and legacy frozen metadata. These checks cover known configured credentials, not arbitrary sensitive content a service may legitimately return. Signing out removes the local OAuth session; disabling an OAuth connector also requires reconnecting after re-enabling.

Setup and access editors use the captured inventory revision. When another device changes a connector, Save retains the draft and requires explicit comparison/reload before retrying. Reload clearly discards the draft and any entered key. Instructions support the same 8,000 UTF-16-unit limit on both clients and the host.

Grok was already registered as a bot provider, but its model-discovery branch returned no models. The adapter now reads the installed CLI’s public model catalog and whitelisted model/effort metadata, without submitting a prompt. Stale metadata cannot add models not advertised by that account. Native effort confirmation remains in place before execution. The new helper is included in the pinned SSH worker package. The separate API provider is labeled **xAI · Grok**, retaining the existing `xai` identity, Responses protocol and saved settings.
