## Compatibility and scope

- Geometric appearances use an optional `shape` field with the existing Koala fallback. All 432 legacy appearance combinations and the original three-field Koala encoding remain supported. Old iPhones can read new shapes safely; their unrelated profile edits retain the saved shape. Explicitly choosing an animal clears geometry, including recovery from an unknown future shape.
- Host and paired catalogs advertise supported shapes. New clients hide unavailable choices, preserve existing saved selections, and block unsupported geometry writes. The internal explicit-clear sentinel is removed before storage and before writing to older hosts.
- Shared thinking, chat history, permissions, configured model identity, remote execution and computer controls retain their existing behavior. Profile edits create no task or model prompt. Maya's model connections remain separate from Strata; this pass performs no Maya service or credential operation.
- The design exposes real existing actions. Daily token budgets, phone routine editing, device-following time zones, push-notification controls, and bot-chat attachments are not added by these visual changes.
