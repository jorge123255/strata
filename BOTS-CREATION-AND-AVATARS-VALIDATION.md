# Bot creation, approvals and expressive avatars

This update follows a read-only comparison with the user's local BotAI source, particularly `CreateBotView.swift`, `AgentProfileView.swift`, `RosterView.swift` and `UI/SmileyAvatar.swift`. BotAI's mobile editor exposes creation, inference settings and character customization directly. Its motion separates working activity, gaze and short reply/tap reactions. Strata retains its own CUA-derived koala and original fox, cat and robot artwork.

## Scope and behavior

Mac/host source is committed at `7d4fbf4ebcc9c177120250a962514b012ff04948`; native iPhone product source is committed at `ef0dbfd364ce13081c2851311baef5fc33dfae2e`. Ask before changes remains the default. Bypass is an explicit profile or new-conversation choice. Existing conversations keep their frozen mode, model and computer; saving a profile does not approve queued requests or start work. Maya and the separate Strata model connections remain distinct.

The paired lifecycle API resolves saved model/computer IDs on the host, accepts public profile fields, and checks the exact latest profile timestamp again after asynchronous inventory reads. Arbitrary credentials and SSH configuration are rejected. Removed selections, stale edits and active direct/team work cannot be overwritten by a phone draft. Saving an idle profile can precede provider sign-in or a saved computer coming online.

Mac setup groups name, character, role/model/effort, computer/workspace and approvals/instructions into short steps. The roster has search and All / Working / Needs attention filters. Compact windows expose the retained query and activity filter through a visible dialog with explicit clearing. Unknown remote effort catalogs offer Provider default while retaining an existing saved effort; this Mac's catalog is not advertised as proof of an SSH computer's support.

The existing koala, fox, cat and robot families retain their stored shapes and palettes. Motion separates working/thinking states, pending approval, sparse focused blinking/gaze and bounded tap/reply reactions. Hidden or offscreen web avatars pause; reduced motion is honored. Roster animation does not use the previous per-avatar 100 ms React interval.

The native phone editor creates and edits bot profiles, avatars, capabilities, saved models and computers, workspace, effort, instructions and approval defaults. A persistent bottom action keeps saving reachable with a long form. Explicit reload only discards a draft after a successful fresh read; stale timestamps cannot overwrite another editor. A captured pairing generation is checked before a queued save and again before selecting a client, so an old draft cannot be created on a newly paired Mac. Older hosts retain read-only compatibility until lifecycle support is available.

## Other differences found in BotAI

These are source observations, not a claim that every BotAI feature has been ported or tested in Strata:

- The mobile roster includes search, pinned bots and an updates filter. This update adds Strata search/activity filters. Pin/mute organization is not part of this update. Shared chat, teams, team Activity, Skills and Connections remain present.
- BotAI's mobile Routines screen can create, edit, pause and run schedules. Strata's Mac has bot routines; the phone does not yet have the same routine editor.
- BotAI mobile stages photos, camera images and files in chat. Strata's bot composer currently directs files to the bot workspace instead.
- BotAI also exposes run history/budgets, notification links, memory management and group-channel controls. These have separate persistence and runtime requirements; visual similarity alone does not establish feature parity.
